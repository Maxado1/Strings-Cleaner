# 📋 Overview
Strings Cleaner is a sophisticated Windows memory manipulation utility designed for security researchers, malware analysts, and forensic investigators. It enables precise scanning and removal of targeted strings from process memory, including support for system-protected processes protected by Protected Process Light mechanisms.

## ✨ Core Features

- 🎯 Targeted Memory Scanning - Efficiently scans allocated memory regions of target processes

- 🔤 Multi-Encoding Support - Handles both ASCII and Unicode/Wide character strings

- ⚡ Multi-Threaded Architecture - Parallel scanning across all available CPU cores (up to 8 threads

- 🛡️ PPL Bypass Capability - Temporarily disables PPL protection

- 🔒 Thread Management - 	Automatic thread suspension/resume during cleaning operations

- 🧩 Pattern Batching - Support for comma-separated multiple string patterns
